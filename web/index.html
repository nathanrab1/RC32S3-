Instalar o gravador

    
O gravador é um pequeno programa que roda no seu computador e envia o código para a placa pela USB.
       Ele só precisa ser instalado uma vez.

    
    
      
  1. Instale o Node.js (versão 18 ou mais nova).
    2. 
      
  2. Baixe a pasta do projeto e abra um terminal dentro da pasta server.
    3. 
      
  3. Rode npm run setup (instala o arduino-cli e o suporte ao ESP32 — demora alguns minutos).
    4. 
      
  4. Rode npm start e deixe o terminal aberto.
    5. 
    

    
Quando o indicador no canto ficar ● verde, é só ligar a placa na USB e clicar em Gravar.

    
Use o Google Chrome ou o Edge. Se o navegador perguntar se o site pode acessar a rede local, clique em Permitir.

    
Se a placa não aparecer: segure o botão BOOT, aperte e solte RESET, e solte o BOOT.

    

  

  

  
  
📂 Solte o arquivo para abrir o projeto (Controle + Carrinho)
